# reo

**Release Date:** November 22, 2026

A lightweight desktop tool for stretching images and videos to custom dimensions in high quality, built for a simple and fast workflow.

## Status
- Non-profit and completely free to use.
- Open to everyone.
- Currently in testing and active development, so updates and changes may happen over time.

## Download
Grab the latest `.zip` archive from the **Releases** section. Each archive includes `reo.exe` and `readme.txt`.

## Windows SmartScreen Notice
When launching `reo.exe` for the first time, Windows SmartScreen may show a blue warning screen (*"Windows protected your PC"*). This is normal for independent or newly built tools without a paid code-signing certificate and does not mean the file is harmful.
1. Click **More info**.
2. Click **Run anyway**.
